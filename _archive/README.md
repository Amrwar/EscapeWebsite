# Archive

Old versions of things kept for reference, not part of the live site. Nothing in this folder is imported or built by the Next.js app (it's outside `app/`, `components/`, and `public/`), so it has no effect on the deployed site.

- **`legacy-static-site/`** — the original plain HTML/CSS/JS version of the site, from before the move to Next.js + TypeScript. See its own README for how to run it.
- **`from-video-hero/`** — the video-background hero (and its poster image, cursor-glow effect, and video file slot) that the 3D scene replaced on the home page.

If you ever want to go back to a plain static site, or reuse a component from here, just ask — nothing here was deleted, only moved.
